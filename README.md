# Ilustração Interativa — Gerador Síncrono Brushless

Uma ilustração interativa em 3D de um **gerador síncrono brushless (AvK DIG 167 g/10)**, apresentada como um modelo em escala navegável direto no navegador.

> Abra o [index.html](./index.html) em qualquer navegador moderno para explorar o modelo. Não requer instalação nem servidor.

## ✨ Recursos

- 🖱️ Navegação 3D interativa (orbitar, aproximar, girar)
- 🔍 Visualização em escala do gerador síncrono brushless
- 📱 Interface responsiva, otimizada para desktop e dispositivos móveis
- ⚡ Aplicação 100% autocontida em um único arquivo HTML (sem dependências externas)

## 🚀 Como usar

1. Baixe o repositório (ou clone com `git clone https://github.com/LDElectric/ilustra-o-interativa---Gerador-sincrono-Brushless.git`)
2. Abra o arquivo `index.html` em seu navegador
3. Explore e interaja com o modelo

## 🧑‍💻 Sobre

Projeto educacional para demonstrar, de forma visual e interativa, a construção e o funcionamento de um gerador síncrono brushless.
